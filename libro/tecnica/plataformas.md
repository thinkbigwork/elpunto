# Plataformas

**Web primero, en computadora y celular, y una sola base de código para empaquetar después.**

| Plataforma | Cuándo | Qué implica |
| --- | --- | --- |
| Web | Lanzamiento | Ya funciona; cobro directo sin comisión de tienda |
| Steam | Durante o después de la Temporada 1 | Alta de [USD 100](https://partner.steamgames.com/doc/gettingstarted/appfee), recuperables tras USD 1.000 de ventas; comisión del [30 %](https://www.geekwire.com/2018/valves-new-steam-revenue-sharing-tiers-spur-controversy-among-indie-game-developers/) |
| Android | Fase 2 | Comisión del [15 % sobre el primer millón anual](https://support.google.com/googleplay/android-developer/answer/112622) en la mayoría de los países |
| iPhone | Fase 2 | Debe ser [más que una web reempaquetada](https://developer.apple.com/app-store/review/guidelines/); comisión del [15 %](https://developer.apple.com/app-store/small-business-program/) para desarrolladores chicos |
| PS5, Switch, Xbox | Solo con éxito probado | Aprobación de cada fabricante, kits, clasificación por edad |
| Facebook y Messenger | No por ahora | Meta cerró su plataforma web anterior el 30 de septiembre de 2026 ([fuente](https://ppc.land/meta-announces-web-games-sunset-by-september-2026/)) |
| Instagram | Solo promoción | Canal de difusión |

Las pistas en la consola y el código fuente solo existen en una computadora: así algunos desafíos se resuelven sí o sí ahí.
