# Accesibilidad

**Que la dificultad venga del juego, no de una barrera física.**

| Barrera | Solución propuesta |
| --- | --- |
| Pistas que son solo sonido | Una alternativa visual sutil para cada sonido-señal |
| Destreza exigente | Modo asistido: más tiempo de reacción, sin acceso a rankings de destreza |
| Color (eras 4 y 5) | Que el color nunca sea la única forma de distinguir algo |
| Destellos | Respetar la preferencia de menos movimiento; destellos suaves |
| Lectura | Tamaño de texto ajustable en los carteles |
