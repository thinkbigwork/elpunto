# Reglas generales

**Castigar el intento fallido, nunca el progreso.**

1. Nada se explica: todo se descubre.
2. Nadie queda trabado para siempre: lo imprescindible reaparece si se pierde y siempre hay camino de vuelta.
3. El progreso se guarda siempre, en todos los dispositivos.
4. Las respuestas no se compran.
5. Lo que se comparte es el método, no la respuesta: cada jugador tiene su semilla.
6. Lo que abre el calendario no se adelanta.

## Penalizaciones

| Tipo de desafío | Si fallás |
| --- | --- |
| Destreza | Volvés al último punto seguro y ves menos unos segundos. El escudo lo evita una vez |
| Persecución | Si un cazador te alcanza, volvés al refugio del laberinto y los cazadores a su origen. El escudo lo evita una vez |
| Atropello en la avenida | Volvés al inicio del mapa. El escudo lo evita una vez |
| Acertijo | Se reinicia. Muchos errores seguidos "enfrían" el mecanismo un rato |
| Contrarreloj | Se reinicia el desafío |
| Alquimia | Perdés los materiales: queda ceniza |
| Exploración | Sin castigo |

## Puertas

- Se abren solo con lo necesario. Llegar sin eso no abre nada.
- Una puerta cerrada tiembla, suena seco y muestra en punteado lo que le falta.
- Lo que bloquea una salida muestra siempre qué pide (lección del prototipo 2).
- Un mundo anexo ya resuelto no vuelve a encerrar al jugador: su portal queda abierto.

## Acertijos de orden

- La secuencia se evalúa recién al completarla: pisar una figura no dice si fue correcta.
- Si la secuencia está mal, las figuras se apagan y el mecanismo se enfría 4 segundos.
- Así no se puede adivinar probando de a una (lección del prototipo 3).

## Construcciones

- Nada que se construye queda mal para siempre: con la barreta, una tabla puesta se levanta y se vuelve a usar.
