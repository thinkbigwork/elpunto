# Desafíos y pistas

**Lo que es información debe verse distinto de lo que es interactivo.** Una pista se mira; un pedestal se pisa.

## Tipos de pista

| Tipo | Ejemplo |
| --- | --- |
| Visual | Una grieta que parpadea |
| Sonora | El chisporroteo de algo roto. Ver [Lenguaje de sonidos](../arte-audio/sonido.md) |
| Escrita | Un cartel, si sabés leer. Ver [Carteles](../contenido/carteles.md) |
| Numérica | Puntos que indican un orden o un código |
| De memoria | Algo visto en un mundo que se usa en otro |
| Temporal | Una puerta que solo se abre a cierta hora real |
| Meta | El código de la página, la consola, el título de la pestaña |
| Geográfica | Un lugar del mundo real |
| Social | Una solución repartida entre varios jugadores |
| Por ausencia | Lo que debería estar y no está |

## Semillas por jugador

Parte de las respuestas cambia para cada jugador: el orden de los pedestales, las formas, un código. Una guía en un foro explica cómo resolver, pero no da la respuesta.

En el prototipo la semilla cambia en cada partida: el orden de las cuatro figuras, la melodía de la vitrina y las cartas de memoria son distintos cada vez que se juega.

## Válvulas de rescate

- Si la comunidad lleva demasiados días trabada, el juego libera una pista extra sin anunciarla.
- Si un jugador está mucho tiempo solo en un lugar, aparecen señales sutiles.
