# Modelo de negocio

**El primer capítulo es gratis en la web y el resto de la temporada se desbloquea con un pase único, con precio regional.**

| Se vende | No se vende, nunca |
| --- | --- |
| Pase de temporada (pago único, capítulos 2 a 5) | Pistas o soluciones |
| Cosméticos: forma del punto, rastro, sonido de pasos | Poderes, chispas, visión |
| Mecenas: tu nombre escondido en el mundo | Tiempo o saltar desafíos |
| Más adelante: objetos físicos que son pistas | Publicidad dentro del juego |

Si las respuestas se compran, los rankings y la comunidad pierden sentido. La publicidad rompe el clima de oscuridad y silencio.

## País de inicio

Argentina primero, después Latinoamérica de habla hispana, España y recién entonces inglés. Precios en pesos y medios de pago locales, ajustables con la inflación.
