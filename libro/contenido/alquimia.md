# Alquimia

**Dos materiales en un crisol dan algo nuevo.** Las recetas no se listan en el juego: se descubren y se comparten.

| Combinación | Resultado |
| --- | --- |
| Tabla + cuerda | Escalera portátil |
| Tabla + tabla | Balsa: cruza agua sin construir |
| Piedra + cuerda | Gancho: cruza huecos |
| Vidrio + chispa | Linterna: un cono de luz hacia adelante |
| Fragmento + fragmento | Una llave nueva |
| Engranaje + chispa | Un mecanismo que se mueve solo |
| Semilla + agua | Planta trepadora |

## Reglas

- El crisol es un lugar fijo del mapa: se pisa llevando los materiales.
- **En el prototipo:** lente + lente + armazón = anteojos, en la mesa de óptico junto a la biblioteca. Si falta algo, muestra en punteado qué.
- Una combinación sin sentido produce ceniza, con el sonido de algo roto.
- Cada receta tiene lógica del mundo real, para poder deducirla.
