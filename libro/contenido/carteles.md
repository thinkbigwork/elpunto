# Carteles y textos

**Leer es una habilidad que se gana.** Antes del libro, los carteles se ven como garabatos; después, el texto aparece letra por letra.

## Estilo

- Una o dos frases. Nunca instrucciones directas.
- Español con voseo, por ahora.
- Todos los textos se guardan aparte para poder traducirlos.
