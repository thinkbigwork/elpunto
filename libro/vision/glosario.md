# Glosario

**Las palabras del proyecto, con un solo significado cada una.**

| Término | Significado |
| --- | --- |
| Temporada | El arco completo de juego, con su final. La primera es *El Despertar* |
| Capítulo | Una parte de la historia, con título propio: un mapa base con sus mundos anexos. Se abre en una fecha fija |
| Zona | Una parte de un mapa con su propio problema central |
| Desafío | Un obstáculo puntual: una puerta, un cruce, un acertijo |
| Mapa base | El lugar principal de un capítulo (una ciudad, un edificio) |
| Mundo anexo | Un lugar inesperado al que se entra desde el mapa base |
| Era visual | El aspecto con el que el jugador ve el mundo; avanza con él |
| Chispa | Objeto que amplía la visión de forma permanente |
| Semilla | Número propio de cada jugador que define parte de las respuestas |
| Refugio | Zona de calma: nada te alcanza y se recarga el escudo |
| Eco | Rastro grabado del paso de otro jugador |
| Crisol | Lugar donde se combinan materiales (alquimia) |
| Llegar | Completar el camino principal y descubrir en quién te convertiste |
