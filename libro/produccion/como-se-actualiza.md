# Cómo se mantiene este libro

**Este libro se actualiza con cada paso del proyecto.** Cuando tomamos una decisión, cambia una mecánica o sale un prototipo nuevo, se actualizan las páginas afectadas y se suma una entrada al [Registro de cambios](../CAMBIOS.md).

## Reglas

1. Una sola fuente de verdad: si algo cambia, cambia acá.
2. Cada página empieza por su conclusión.
3. Lo propuesto se marca como "Propuesto"; lo que ya existe, "En prototipo".
4. Las decisiones pasan de [Decisiones pendientes](../produccion/decisiones.md) a "Ya decidido" con su fecha.
5. Las páginas tocadas en el último paso aparecen marcadas como "nuevo" en el índice.

## Dónde vive

Desde el 2 oct 2026 el libro vive en el repositorio del juego, como páginas Markdown en la carpeta `libro/`, con un índice `SUMMARY.md` (el formato de GitBook). Cada cambio al juego actualiza ahí mismo las páginas afectadas y el archivo `CAMBIOS.md`. La versión web del libro se puede seguir publicando a partir de esos archivos.

## Categorías

Siguen la estructura habitual de un documento de diseño de juego: visión, mundo, jugabilidad, contenido, arte y audio, niveles, técnica, negocio y producción.
