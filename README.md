# El Punto

Un punto blanco en una pantalla negra. Sin reglas, sin instrucciones. Lo demás se descubre.

## Jugar

Abrí `juego/el-punto.html` en el navegador, o entrá a https://elpunto-mu.vercel.app. Flechas o WASD para moverse; también anda con un control de PS4 o Xbox (cruceta o palanca izquierda).

## Libro de diseño

Todo el diseño está en [`libro/`](libro/README.md): empezá por el [índice](libro/SUMMARY.md) o el [registro de cambios](libro/CAMBIOS.md).

## Pruebas

```
npm install
npx playwright install chromium
npm test
npm run validar:ciudad
```
