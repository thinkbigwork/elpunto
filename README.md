# El Punto

Un punto blanco en una pantalla negra. Sin reglas, sin instrucciones. Lo demás se descubre.

## Jugar

Abrí `juego/el-punto.html` en el navegador. Flechas para moverse.

## Libro de diseño

Todo el diseño está en [`libro/`](libro/README.md): empezá por el [índice](libro/SUMMARY.md) o el [registro de cambios](libro/CAMBIOS.md).

## Pruebas

```
npm install
npx playwright install chromium
npm test
```

## Trabajar con Claude Code

Abrí esta carpeta con Claude Code. Las reglas del proyecto están en `CLAUDE.md` y se cargan solas.
